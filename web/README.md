# web

Account dashboard and landing page at https://relaynet.network, deployed as
a Cloudflare Worker with static assets. Static files, no build step.

| File | Purpose |
|---|---|
| `index.html` | Landing page (signed out) and dashboard (signed in). |
| `app.js` | Auth0 sign-in, calls to the relay's `/api/me` and `/api/orgs` routes, rendering: account, usage, sessions, tokens, and organizations (switcher, members, invitations; a `#invite=<token>` link (or the older `?invite=<token>`) is accepted after sign-in and the token is removed from the address bar at once). API data is only ever inserted as text nodes. |
| `config.js` | Public configuration: relay URL, Auth0 domain, client id and audience, Turnstile sitekey. |
| `styles.css` | Light and dark themes via CSS tokens. |
| `_headers` | Content Security Policy and other response headers applied to the static assets. |
| `docs.html`, `docs.md`, `llms.txt` | Generated by `docs/build.py` from `docs/docs.md`; edit that. |

## Deploy

Merging to `main` deploys (`.github/workflows/deploy-web.yml`, with
`cloudflare/wrangler-action`); `gh workflow run deploy-web.yml` redeploys.
To see what would be uploaded:

```sh
cd web && npm ci && npx wrangler deploy --dry-run
```

`wrangler.jsonc` names the Worker, points the assets at `./public` and binds
the apex custom domain `relaynet.network`. The page's origin must stay listed
in `ALLOWED_ORIGINS` in `../relay/fly.toml`.

## Local development

Serve the directory on port 5173 (that origin is allowed in the Auth0 app):

```sh
python3 -m http.server 5173 -d web
```

Sign-in works locally, but the relay only accepts browser calls from the
production origin, so the dashboard's data calls return 403 unless
`http://localhost:5173` is added to `ALLOWED_ORIGINS` for a dev relay.

## Connecting

```js
const ws = new WebSocket("wss://relay.relaynet.network", ["relay.v1", "relay.token." + token]);
```

`token` is an API token from the dashboard, an Auth0 access token with audience
`https://relay.relaynet.network`, or an anonymous token from
`POST https://relay.relaynet.network/api/anon/token` with a `turnstileToken`
in the JSON body.
