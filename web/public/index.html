Give your browser VM a network.

relaynet is a hosted relay for virtual machines that run in a web page. Point the VM's network adapter at a WebSocket and it gets DNS, TCP and UDP to the public internet, with per-account limits and nothing reachable inside the relay's own network.

relaynet is in an invite-only beta. Sign in, then redeem your invite code. By signing in you agree to the Terms and Acceptable Use Policy.

See how it works

1. Get a token

Sign in with your invite and create an API token from your dashboard.

2. Open the WebSocket

Connect to wss://relay.relaynet.network with the token in the subprotocol list. Ethernet frames go in, Ethernet frames come out.

3. Boot the VM

The relay answers DHCP and ARP, forwards TCP and UDP, and resolves DNS. Works with v86, container-in-browser projects, or anything that speaks the protocol.

Connecting from a page

const ws = new WebSocket("wss://relay.relaynet.network", [
  "relay.v1",
  "relay.token." + token,   // an API token from your dashboard
]);
// hand `ws` to your VM's network adapter

Browsers cannot set headers on a WebSocket, so the token travels as a subprotocol entry. Non-browser clients may send Authorization: Bearer instead.
